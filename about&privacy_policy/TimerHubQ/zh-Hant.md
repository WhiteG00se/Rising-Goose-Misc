## 儲存在你裝置上的資料

- Timer Hub Q 會將已儲存的世界時鐘位置和時區、鬧鐘及鬧鐘記錄、計時器及計時器記錄、秒錶資料和封存的工作階段、設定，以及本文件的快取副本儲存在應用程式的私人儲存空間中。
- 計時器名稱、資料夾名稱、秒錶工作階段標題、排程、時長、圈數和相關時間戳記會保留在你的裝置上，不會傳送到任何外部伺服器進行處理。

## 位置資料

- Timer Hub Q 不會要求或存取你裝置的位置。
- 世界時鐘搜尋是可選的。搜尋時，你輸入的文字和應用程式選取的語言會傳送至 Open-Meteo，以尋找相符的位置。
- 如果你新增搜尋結果，Timer Hub Q 會在裝置上儲存其城市名稱、國家代碼和時區。不會儲存該結果的座標。

## 外部服務

- Timer Hub Q 的開發者不營運後端，也不會接收 Open-Meteo 的要求。
- Timer Hub Q 會透過 HTTPS 將世界時鐘搜尋字詞和選取的語言傳送給 Open-Meteo。
- 網絡流量在傳輸期間使用 HTTPS 加密。
- 在應用程式內開啟本文件時，文件會透過 HTTPS 從 Timer Hub Q 的公開 GitHub 儲存庫下載。
- 外部服務可能根據其自身政策記錄 IP 位址、搜尋字詞、要求時間或技術細節。Open-Meteo 表示，疑難排解記錄會在 90 天後刪除。
