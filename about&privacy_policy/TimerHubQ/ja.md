## データソース

- 世界時計の場所検索には Open-Meteo を使用します。データは CC BY 4.0 に基づいてライセンスされています。
- Open-Meteo: 自動（日照）.
- Timer Hub Q は表示のためにこれらのデータを処理しており、Open-Meteo とは提携しておらず、同サービスから承認も受けていません。

- Open-Meteo: https://open-meteo.com/en/licence

## デバイスに保存されるデータ

- Timer Hub Q は、保存した世界時計の場所とタイムゾーン、アラームとアラーム履歴、タイマーとタイマー履歴、ストップウォッチのデータとアーカイブ済みセッション、設定、この文書のキャッシュコピーをアプリの専用ストレージに保存します。
- タイマー名、フォルダー名、ストップウォッチセッションのタイトル、スケジュール、期間、ラップ、関連するタイムスタンプはデバイスに残り、処理のために外部サーバーへ送信されません。
- 丸めた座標、日の出、日の入り、日照時間、タイムゾーン、取得時刻はテーマとオフライン利用のために端末内にキャッシュされます。このキャッシュはアプリのエクスポート、Android のバックアップ、端末間の転送には含まれず、Android が削除する場合があります。アプリのキャッシュやデータを消去するか、アンインストールすると削除できます。外部提供者のログは削除されません。

## 位置情報

- 自動（日照）はアプリを開いている間、スマートフォンのおおよその位置を Open-Meteo に送信し、日の出と日の入りの時刻を取得します。位置や日照データを取得できない場合は、システム設定に従います。
- 位置情報の許可は任意です。他のテーマは許可なしで使えます。Timer Hub Q は使用中のおおよその位置だけを要求し、正確な位置やバックグラウンドの位置は要求しません。座標は Open-Meteo への送信やキャッシュ保存の前に 0.1 度単位に丸められます。許可済みの場合、テーマ選択画面を開いている間にもデータを事前取得することがあります。位置へのアクセスを止めるには Android の設定で許可を取り消してください。
- 世界時計の検索は任意です。検索すると、入力したテキストとアプリで選択した言語が、一致する場所を見つけるために Open-Meteo へ送信されます。
- 検索結果を追加すると、Timer Hub Q は都市名、国コード、タイムゾーンをデバイスに保存します。結果の座標は保存しません。

## 外部サービス

- Timer Hub Q の開発者はバックエンドを運営しておらず、Open-Meteo のリクエストを受け取りません。
- Timer Hub Q は世界時計の検索語と選択した言語を HTTPS 経由で Open-Meteo に送信します。
- ネットワーク通信は HTTPS を使用して転送中に暗号化されます。
- アプリ内でこの文書を開くと、Timer Hub Q の公開 GitHub リポジトリから HTTPS 経由でダウンロードされます。
- 外部サービスは、それぞれのポリシーに従って IP アドレス、座標、検索語、リクエスト時刻、技術的詳細を記録する場合があります。Open-Meteo は、座標を含むトラブルシューティングログを 90 日後に削除すると説明しています。
- Open-Meteo: https://open-meteo.com/en/terms#privacy

## バックアップ、保持、削除

- デバイスと設定によっては、Android、Google、またはデバイスメーカーが、Timer Hub Q のローカル保存データをクラウドバックアップやデバイス転送に含める場合があります。開発者はこれらのコピーを受け取らず、管理もできません。ユーザーはデバイスまたはアカウントのバックアップ設定で管理できます。アプリをアンインストールした後もバックアップが残ることがあります。
- ローカルデータは、置き換えられる、アプリから削除される、Android の設定で消去される、またはアプリのアンインストール時に削除されるまで保持されます。
