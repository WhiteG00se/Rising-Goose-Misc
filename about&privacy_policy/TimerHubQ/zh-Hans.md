## 数据来源

- Open-Meteo 用于世界时钟的位置搜索。其数据依据 CC BY 4.0 获得许可。
- Timer Hub Q 处理这些数据以供显示，并不隶属于 Open-Meteo，也未得到其认可。

- Open-Meteo: https://open-meteo.com/en/licence

## 存储在设备上的数据

- Timer Hub Q 将已保存的世界时钟位置和时区、闹钟及闹钟记录、计时器及计时器记录、秒表数据和已归档会话、设置以及本文档的缓存副本存储在应用的私有存储中。
- 计时器名称、文件夹名称、秒表会话标题、日程、时长、圈数和相关时间戳会保留在你的设备上，不会发送到外部服务器进行处理。

## 位置数据

- Timer Hub Q 不会请求或访问设备的位置。
- 世界时钟搜索是可选的。搜索时，你输入的文本和应用中选择的语言会发送到 Open-Meteo，以查找匹配的位置。
- 如果你添加搜索结果，Timer Hub Q 会在设备上保存城市名称、国家代码和时区。不会保存结果的坐标。

## 外部服务

- Timer Hub Q 的开发者不运营后端，也不会接收 Open-Meteo 的请求。
- Timer Hub Q 通过 HTTPS 将世界时钟搜索词和选择的语言发送到 Open-Meteo。
- 网络流量在传输过程中使用 HTTPS 加密。
- 在应用内打开本文档时，文档会通过 HTTPS 从 Timer Hub Q 的公开 GitHub 存储库下载。
- 外部服务可能根据其自身政策记录 IP 地址、搜索词、请求时间或技术细节。Open-Meteo 表示，故障排查日志会在 90 天后删除。

## 备份、保留和删除

- 根据设备和设置，Android、Google 或设备制造商可能会将 Timer Hub Q 在本地存储的所有数据——包括世界时钟条目、闹钟及闹钟记录、计时器及计时器记录、秒表数据和已归档会话、设置以及本文档的缓存副本——纳入云备份或设备转移。开发者不会接收或控制这些副本；你可以在设备或帐户的备份设置中管理它们。卸载应用后，备份可能仍会保留。
- 本地数据会一直保留，直到被替换、通过应用移除、在 Android 设置中清除，或在卸载应用时删除。
