## 存储在设备上的数据

- Timer Hub Q 将已保存的世界时钟位置和时区、闹钟及闹钟记录、计时器及计时器记录、秒表数据和已归档会话、设置以及本文档的缓存副本存储在应用的私有存储中。
- 计时器名称、文件夹名称、秒表会话标题、日程、时长、圈数和相关时间戳会保留在你的设备上，不会发送到外部服务器进行处理。
- 舍入后的坐标、日出、日落、日照时长、时区和获取时间会缓存在设备上，供主题及离线使用。此缓存不包含在应用导出、Android 备份或设备迁移中，Android 可能清除它。清除应用缓存或数据，或卸载应用即可删除。这不会删除外部服务提供商的日志。

## 位置数据

- 自动（日光）在应用打开时将手机的大致位置发送给 Open-Meteo，以获取日出和日落时间。如果位置或日光数据不可用，则跟随系统。
- 位置权限是可选的，其他主题无需此权限即可使用。Timer Hub Q 仅请求使用应用时的大致位置，从不请求精确位置或后台位置。坐标在发送至 Open-Meteo 或缓存之前会四舍五入到 0.1 度。已授予权限时，打开主题选择器也可能预加载数据。在 Android 设置中撤销位置权限即可停止位置访问。
- 世界时钟搜索是可选的。搜索时，你输入的文本和应用中选择的语言会发送到 Open-Meteo，以查找匹配的位置。
- 如果你添加搜索结果，Timer Hub Q 会在设备上保存城市名称、国家代码和时区。不会保存结果的坐标。

## 外部服务

- Timer Hub Q 的开发者不运营后端，也不会接收 Open-Meteo 的请求。
- Timer Hub Q 通过 HTTPS 将世界时钟搜索词和选择的语言发送到 Open-Meteo。
- 网络流量在传输过程中使用 HTTPS 加密。
- 在应用内打开本文档时，文档会通过 HTTPS 从 Timer Hub Q 的公开 GitHub 存储库下载。
- 外部服务可能会根据其自身政策记录 IP 地址、坐标、搜索词、请求时间或技术细节。Open-Meteo 表示，包含坐标的故障排除日志会在 90 天后删除。
- Open-Meteo: https://open-meteo.com/en/terms#privacy

## 备份、保留和删除

- 根据设备和设置，Android、Google 或设备制造商可能会将 Timer Hub Q 本地存储的数据纳入云备份或设备迁移。开发者不会接收或控制这些副本；用户可以在设备或账户的备份设置中管理它们。卸载应用后，备份可能仍会保留。
- 本地数据会一直保留，直到被替换、通过应用移除、在 Android 设置中清除，或在卸载应用时删除。
